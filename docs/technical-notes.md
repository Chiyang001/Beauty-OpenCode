# Beauty OpenCode

Windows OpenCode 的 Codex 风格桌面布局补丁。保留 OpenCode 品牌及模型、会话、文件、工具等原生功能。

## 一键使用

1. 完全退出 OpenCode。
2. 双击 `dist/electron/Beauty-OpenCode-Electron.exe`（Electron 便携版，免安装，不需要 Python / Node）。
3. 左侧选择“全新改版”或“经典模式”，右侧查看真实界面预览。
4. 点击“应用”切换，然后点击“打开 OpenCode”。经典模式恢复原版资源。

兼容旧版 Python 工具的备份和校验记录，不需要先手动恢复。工具始终保留最初的原版备份。

## v2 实际改动

- 重建常驻左侧导航栏、项目和聊天侧栏，替代顶部标签页导航。主页同时展示项目和最近聊天，点击主页不创建会话；项目及最近聊天可单独查看。
- 点击项目名称只折叠 / 展开其会话，不创建草稿；项目不可重命名，仅对话可重命名；项目悬浮时可删除，确认后清除主目录和关联工作区全部对话及草稿，再移除项目，保留代码文件；聊天悬浮时可置顶 / 取消置顶，置顶状态按服务器持久保存在本机。
- 删除成功后同步移除项目 / 最近聊天索引及置顶记录；启动和切换服务器时刷新索引，清理旧缓存。
- 修复真实会话菜单重命名，保存后刷新会话列表；侧栏收起 / 展开带动画，并尊重系统减少动画设置。
- 发送 / 停止按钮统一为 28px 圆形，白色图标；停止时蓝色，空输入时灰色。
- 接入原生项目、会话索引、草稿及设置控制器。项目、已有聊天和草稿均可直接打开。
- 提供侧栏搜索、折叠项目、最近聊天及草稿切换 / 关闭。
- 保留欢迎页的原版 OpenCode 字标及项目欢迎语；首页主按钮为“打开项目”，点击调用原生项目选择器；左上角品牌标题无下拉菜单。
- 将原生输入框放到底部，并将原生项目信息条放在输入框上方。
- 重做顶部文件 / 编辑 / 视图 / 帮助菜单，并保留 Windows 原生最小化、最大化和关闭控件及窗口拖动。
- 统一字体、灰色层次、蓝色发送按钮、圆角、菜单、设置页面及滚动条。

设置采用整页分类导航、搜索框和卡片布局；新版隐藏“外观”设置区块，保留其他原生通用、快捷键、服务器、提供商及模型控件；可点击左侧主页图标或“返回聊天”退出。搜索筛选当前分类的设置项，并高亮匹配的分类标题；2.x 同时保留原生跨分类搜索结果和跳转。

`Ctrl+B` 切换侧栏。视图菜单可返回 OpenCode 原生首页，访问其项目管理等功能。

这是视觉及导航布局复刻；没有复制 Codex 的后端、账户、审批、任务管理等独有功能。不会新增假的麦克风、权限开关或其他没有原生支持的控件。

## 兼容、备份与更新

属于独立 Electron 资源补丁，不是官方 OpenCode 插件。支持 Windows Electron OpenCode，不设版本号上下限。已通过本机 OpenCode 2.0.26 原包的补丁完整性与恢复测试，同时保留 1.18.x 的旧架构挂载逻辑。支持旧包名 `@opencode-ai/desktop` 和新包名 `@opencode/desktop`。新版按原生垂直导航 API 和语义属性识别结构，不依赖压缩变量名或构建哈希文件名。应用前检查包名、资源结构及具体挂载点，结构不匹配时停止，避免写入无效补丁。

原包：`resources/app.asar.beauty-original`。
校验记录：`resources/beauty-opencode.json`。
修改范围：renderer 主 JS、设置模块 JS、主 CSS 及 HTML 页面标记。其余打包文件及 unpacked 文件不变。

通过 SHA-256 检查原包和备份，使用临时文件及原子替换；运行中的 OpenCode 会拒绝修改。中断升级的记录包含前后两个摘要，可恢复到原版。资源被更新或被其他程序修改时拒绝恢复旧包，避免用旧版本覆盖新版。

### OpenCode 2.0.26 及后续版本

2.x 使用完整迁移路径，复用旧版外壳、主题、壁纸、菜单和对话控件，通过语法树识别新版控制器并桥接会话 `location.directory`、分页列表、缓存与删除接口。恢复经典模式后仍按原生偏好显示，不改写用户保存的标签布局。

已迁移并在真实 2.0.26 临时副本中检查：

- 自定义主页、项目分组、最近聊天、侧栏搜索与折叠、项目菜单、置顶及草稿切换 / 关闭；重复点击新聊天复用同目录草稿。
- 聊天右键重命名，删除确认与项目清理；项目清理覆盖分页、子会话、已归档会话及关联工作区，保留代码文件。
- 顶部文件 / 编辑 / 视图 / 帮助菜单、原生窗口控件、Ctrl+B、对话快速定位。
- 草稿欢迎语、底部输入框及其上方的原生项目信息条、圆形发送 / 停止按钮、思考强度滑块。
- 默认与八套主题，深色 / 浅色 / 跟随系统、自定义壁纸持久保存、上传与清除、设置分类与搜索。保留新版原生字体设置和其他设置分类。

不依赖具体构建哈希或压缩变量名；后续版本沿用相同语义结构时可继续适配，结构变化时拒绝写入并需要更新适配。

更新 OpenCode 前先恢复原版。新版资源结构兼容时可直接启用，无需添加版本白名单。

### 3.1.1 设置页修正

设置页取消外框圆角，聊天外壳在设置中只占 52px 导航栏，避免遮挡分类点击。搜索框填满 260px 侧栏，保留原生搜索图标、结果与清除按钮。设置行使用 13px 标题、12px 描述和 13px 上下内边距，卡片与下拉按钮统一圆角，开关使用 34×20px 胶囊轨道与圆形滑块。

`node inspection/verify-settings-pointer.cjs` 使用真实鼠标点击全部 12 个分类、搜索、原生下拉菜单、开关与返回按钮，检查覆盖层宽度、外框圆角和控件尺寸；开关测试后恢复原值。

### 3.1.2 控件修正

取消设置与聊天搜索框聚焦后的边框、光圈和阴影，设置区隐藏滚动条并保留滚轮与键盘滚动。2.x 界面主题下拉使用随主题变化的圆角菜单，支持方向键、Home / End、Enter、Escape 和点击外部关闭。模型选择和推理强度在输入框右侧排列，附件按钮保留在左侧。

`node inspection/verify-controls.cjs` 检查搜索框及其容器和伪元素的聚焦样式、滚动功能、主题菜单键盘操作、模型与推理控件位置和原生模型菜单。

### 3.1.3 图片与全局控件修正

修复打包期间预览截图变化导致后续图片资源偏移的问题。打包后逐文件对照源码、图片和预览资源，并在补丁应用前检查主题 PNG 文件头。主题、壁纸和预览资源通过字节校验后才能发布。

模型管理、连接提供商和其他原生窗口共享圆角面板、按钮与胶囊开关；输入框及其容器不显示聚焦光圈或阴影动画，Git 状态标签透明。`node inspection/verify-all-dialogs.cjs` 检查图片解码、模型和提供商弹窗、开关恢复、输入样式及 Git 标签。

### 3.1.6 OpenCode 2.2.0 适配

- Solid 的 `createReaction` 与 `createEffect` 共享部分实现特征，旧检查因此报告 `effect` 不唯一。现在沿 `onMount` 调用关系识别响应式函数；路径工具按正反斜杠参数识别，侧栏只修改主布局内的垂直导航条件，保留其他导航分支。
- 草稿输入区新增 `new-session-composer` 插槽。改用语义插槽及字标、输入框的共同容器定位，在新版绝对定位外层正确应用底部布局，移除单子项被误当作项目信息托盘的背景与缩进。
- 时间轴从原生消息数据读取已加载用户消息，覆盖虚拟列表中没有挂载 DOM 的消息；点击标记委托原生消息锚点显示目标行。旧版普通消息列表仍使用原有滚动定位。
- 项目移除兼容新 `project.hide` 与旧 `project.close`；导出调用新版原生会话接口。保留完整会话位置字段，分支提示兼容新版 VCS 数据及没有 Git 分支的项目。
- 保留原生设置搜索的 DOM 归属、跨分类索引和键盘操作。外观页按原生标题、主题壁纸卡、字体与原生控件排序，取消重复标题。配对翻译兼容拆分后的语言描述对象。
- 补齐新版输入框过渡、队列、活动、待办、工具请求、网页搜索、模型选择和提示框样式；适配设置容器 800px 折叠及窄窗主题图库。

`npm test` 包含真实 ASAR 完整性和恢复、挂载歧义、两代侧栏、语言描述及新版桥接回归。`npm run test:ui` 通过 Electron 的 Chromium 加载真实 2.2.0 主 CSS 和后加载的动态 CSS，检查 1440、1000、760、390px 四种宽度，以及旧版控件和流式时间轴。

`npm run test:native-ui` 用 Playwright 连接独立 OpenCode 测试副本的本机调试端口。先为测试副本配置隔离用户目录并启用 `--remote-debugging-port=9224`；默认地址为 `http://127.0.0.1:9224`，可用 `OPENCODE_CDP_URL` 覆盖。Playwright 在模块搜索路径之外时，将 `BEAUTY_PLAYWRIGHT` 设为其模块绝对路径；设置 `BEAUTY_UI_SCREENSHOTS` 可保存截图。

真实界面回归覆盖首页、菜单、Ctrl+B、草稿复用及底部位置、模型与思考强度、会话菜单、对话定位、13 个设置分类、索引搜索、默认及八套主题、图片解码、深浅色与键盘选择。主题与颜色模式在测试结束后恢复。2.2.0 实际截图位于 `screenshots/opencode-2.2.0-*.png`。

### 3.1.7 设置对齐与合并模型控件

主题卡片只设置上下外边距，左右继续使用与原生标题、字体卡片相同的居中规则。隐藏 `interface-mode` 的 Top tabs、Side tabs、Inbox 三种选项，保留经典模式下的原生偏好。

输入区保留 Solid 管理的原生模型按钮，在存在强度选项时通过同一个胶囊按钮展示模型名与强度。点击名称打开模型列表，点击强度打开含模型入口和重置按钮的滑块面板。原生模型列表及首次使用的免费模型列表均定位到按钮上方，保持搜索、键盘选择与模型管理功能，并取消背景遮罩；窄窗自动限制宽高。原生分层 CSS 的重要尺寸规则通过局部定位尺寸覆盖，避免菜单落回窗口中央或超出边缘。

气泡周期改为 5.2–6.4 秒，水平运动使用 linear，透明度固定 0.55；高强度下的装饰点仅在 0.55–0.60 范围内缓慢变化。回归检查包含四种宽度的卡片对齐，以及气泡分时采样的匀速和稳定透明度。

### 3.1.8 思考面板细节

移除合并按钮与面板标题的闪电图标，以及普通模型按钮的占位字符。面板里的强度标题和模型名称放进同一个原生按钮，鼠标悬浮、点击及键盘操作覆盖两行文字整体；重置按钮保持独立。

刻度保留原始位置，当前档位及左侧已填充的点用 visibility 隐藏，回调档位时恢复未填充的点。24 个气泡分为 2.8、3.0、3.2 秒三组，每组均匀错开相位并使用负延迟，打开面板就有连续流动，循环边界不出现整段空白。保持匀速和固定透明度。隐藏原生 new-session-tip，移除提供商推广提示。

Chromium 回归覆盖两行文字点击、各档位刻度及位置稳定、6.4 秒循环的气泡密度与最大间隙、图标与推广提示隐藏，并继续运行原包完整性及实际界面回归。

### 3.1.9 统一思考面板入口

支持思考强度的模型，输入区胶囊按钮的模型名、强度和箭头统一打开思考面板；切换模型通过面板内的两行标题按钮进入。不支持调整强度的模型仍直接打开原生模型列表。

参考气泡图改为 14 个大小、位置和速度各异的粒子，2.7–3.8 秒匀速循环，起始相位适度打散，保留稳定透明度和连续流动。点击路径与气泡循环均纳入 Chromium 回归。

### 3.1.10 项目移除与右键菜单

修复新版项目隐藏接口的参数类型：原生 `hide` 接收完整项目对象，旧版 `close` 仍接收目录字符串。项目移除流程先检查接口，再清理项目会话和当前服务器下的相关草稿，最后隐藏项目；删除失败时停止后续步骤。项目行右键复用更多按钮的项目菜单，与会话行一致。

新增回归直接运行本机原包中的项目隐藏方法，配合测试会话、草稿和项目列表验证完整流程；同时检查旧接口、删除失败及接口缺失。实际界面回归检查项目右键菜单和取消移除，不删除用户项目或对话。

### 3.1.11 简体中文补全

按语义键定位原生简体中文语言包，补齐时间轴宽度、后台活动、文件更改、布局、通知、实验功能、模型与提供商管理等缺失翻译。覆盖 13 个内置模块的语言描述和延迟加载的中文资源，包括浏览器、终端、文件、审查、会话详情、更新、SSH、WSL、办公文件预览和旁支提问。已有原生中文措辞保留；占位参数、模型名、品牌、路径、快捷键及其他语言资源保持原样。

快捷键目录曾持久保存英文命令标题；现在仅在简体中文界面渲染目录时转换已知标题和描述，不改写缓存及自定义命令。补丁修订校验包含翻译资源和语言适配代码。

模型列表按分组配置的翻译键识别最近使用入口，移除传入展示层的 Recent 列表，保留提供商分组、收藏、搜索和模型使用记录；不依赖界面语言隐藏标题。

回归验证中文键覆盖、插值参数、重复应用、原生中文保留、其他语言隔离、内置模块资源及缓存命令显示，并逐页检查 13 个设置分类。修改和验证后按进程检查及完整性校验流程应用本机补丁，不生成便携包。

## 开发

新版切换工具使用 Electron / HTML / CSS / Node.js，运行时不调用 Python。

`npm install` 安装依赖，`npm start` 启动，`npm test` 验证补丁完整性与恢复，`npm run build` 生成 Windows 便携版。

`electron/patch.cjs` 负责资源及进程检查、备份和恢复；`electron/asar.cjs` 负责资源重打包和完整性块。旧 Python 源码保留供历史验证使用。

Python 3.10+，源码运行：`python beauty.py`。
打包：`python -m PyInstaller --noconfirm --onefile --windowed --name Beauty-OpenCode --add-data "assets;assets" beauty.py`。

`assets/codex-shell.js` 被附加到原生 renderer 模块中，使用其真实 Solid 控制器；`assets/codex.css` 提供视觉和布局覆盖。安装器保留原始备份，可直接升级补丁。
